# 04. Manual de usuario

## Estado

Este manual describe la estructura inicial del proyecto. Los comandos de ejecución
se completarán cuando se definan la fuente, el destino y las dependencias del ETL.

## Requisitos previos

- Python 3 instalado (versión exacta pendiente de definir).
- Acceso autorizado a la fuente y al destino, cuando se configuren.
- Dependencias por documentar cuando se implemente la carga.

## Preparación

1. Clona o descarga el proyecto.
2. Crea y activa un entorno virtual de Python.
3. Instala las dependencias que se documenten para la implementación final.
4. Configura los parámetros localmente; no publiques contraseñas ni archivos `.env`.

## Ejecutar la carga

_Pendiente de implementación._ Consulta `src/etl/cargar_datos.py` y actualiza esta
sección con el comando, argumentos, entradas y salidas aprobados antes de operar
el proceso.
