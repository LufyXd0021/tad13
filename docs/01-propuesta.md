# 01. Propuesta

## Resumen

TAD-13 propone organizar y automatizar el procesamiento de datos mediante un flujo
ETL (extracción, transformación y carga). El caso de uso y las fuentes concretas se
deben definir con los responsables del proyecto.

## Problema u oportunidad

_Describe qué tarea relacionada con los datos se quiere mejorar, cómo se realiza
actualmente y cuáles son sus limitaciones._

## Objetivo

_Define el resultado verificable que se espera obtener._

## Usuarios y beneficiarios

_Identifica quién prepara, administra y consume los datos._

## Alcance

### Incluye

- Documentar el proceso y sus decisiones.
- Implementar el flujo ETL una vez definidas las fuentes y el destino.
- Validar los datos de acuerdo con reglas acordadas.

### No incluye (por definir)

- Fuentes, reportes o integraciones no aprobados para el proyecto.

## Requisitos y criterios de aceptación

_Enumera requisitos funcionales, restricciones y criterios medibles para aceptar
una carga._

## Supuestos y riesgos

_Registra disponibilidad, calidad, permisos y volumen de los datos, así como los
riesgos y sus mitigaciones._
